     8→  1008→## Auto-Generated Table of Contents
     9→  1009→
    10→  1010→### ❌ FORBIDDEN: Manual Table of Contents
    11→  1011→**NEVER manually create TOC with hardcoded page numbers.**
    12→  1012→
    13→  1013→### ⚠️ MANDATORY: TOC requires a cover page
    14→  1014→**Unless the user explicitly requests no cover, if a document has a Table of Contents, it MUST have a cover page.** Structure: Cover (page 1) → TOC (page 2) → Content (page 3+). Do not generate a TOC without a preceding cover page.
    15→  1015→
    16→  1016→### ✅ ALWAYS use auto-generated TOC:
    17→  1017→
    18→  1018→```python
    19→  1019→from reportlab.platypus import SimpleDocTemplate, Paragraph, PageBreak, Spacer
    20→  1020→from reportlab.platypus.tableofcontents import TableOfContents
    21→  1021→from reportlab.lib.utils import simpleSplit
    22→  1022→import hashlib
    23→  1023→
    24→  1024→class TocDocTemplate(SimpleDocTemplate):
    25→  1025→    def afterFlowable(self, flowable):
    26→  1026→        if hasattr(flowable, 'bookmark_name'):
    27→  1027→            level = getattr(flowable, 'bookmark_level', 0)
    28→  1028→            text = getattr(flowable, 'bookmark_text', '')
    29→  1029→            key = getattr(flowable, 'bookmark_key', '')
    30→  1030→            # MUST pass key as 4th element - without it, TOC entries won't have clickable links
    31→  1031→            self.notify('TOCEntry', (level, text, self.page, key))
    32→  1032→
    33→  1033→doc = TocDocTemplate("document.pdf", pagesize=letter)
    34→  1034→story = []
    35→  1035→
    36→  1036→toc = TableOfContents()
    37→  1037→toc.levelStyles = [
    38→  1038→    ParagraphStyle(name='TOCHeading1', fontSize=14, leftIndent=20, fontName='FreeSerif'),
    39→  1039→    ParagraphStyle(name='TOCHeading2', fontSize=12, leftIndent=40, fontName='FreeSerif'),
    40→  1040→]
    41→  1041→story.append(Paragraph("<b>Table of Contents</b>", styles['Title']))
    42→  1042→story.append(toc)
    43→  1043→story.append(PageBreak())
    44→  1044→
    45→  1045→def add_heading(text, style, level=0):
    46→  1046→    # Generate a unique bookmark key for this heading
    47→  1047→    key = 'h_%s' % hashlib.md5(text.encode()).hexdigest()[:8]
    48→  1048→    p = Paragraph('<a name="%s"/>%s' % (key, text), style)
    49→  1049→    p.bookmark_name = text
    50→  1050→    p.bookmark_level = level
    51→  1051→    p.bookmark_text = text
    52→  1052→    p.bookmark_key = key  # This key enables clickable TOC links
    53→  1053→    return p
    54→  1054→
    55→  1055→# ⚠️ Orphan Heading Prevention (NOT a page break rule)
    56→  1056→# If an H1 heading would appear in the bottom 15% of the page with no room
    57→  1057→# for at least a few lines of content, push it to the next page.
    58→  1058→# This is NOT "every H1 starts a new page" — it only triggers when the heading
    59→  1059→# would be orphaned at the very bottom.
    60→  1060→available_height = A4[1] - top_margin - bottom_margin
    61→  1061→H1_ORPHAN_THRESHOLD = available_height * 0.15  # ~100pt ≈ 3.5cm — enough for heading + 2 lines
    62→  1062→
    63→  1063→def add_major_section(text, style):
    64→  1064→    """Add an H1-level heading with orphan prevention (NOT forced page break)."""
    65→  1065→    return [
    66→  1066→        CondPageBreak(H1_ORPHAN_THRESHOLD),  # Only break if heading would be orphaned at page bottom
    67→  1067→        add_heading(text, style, level=0),
    68→  1068→    ]
    69→  1069→
    70→  1070→story.extend(add_major_section("Chapter 1: Introduction", styles['Heading1']))
    71→  1071→# ... content ...
    72→  1072→
    73→  1073→doc.multiBuild(story)  # MUST use multiBuild for TOC
    74→  1074→```
    75→  1075→
    76→  1076→**⚠️ CRITICAL TOC LINK RULES:**
    77→  1077→1. `afterFlowable` MUST pass `key` as the 4th element in the notify tuple - without it, TOC entries have no clickable links
    78→  1078→2. `add_heading` MUST set `bookmark_key` AND embed `<a name="key"/>` in the Paragraph text - this creates the link destination
    79→  1079→3. The key must be unique per heading - use a hash of the heading text

    81→  1081→### TOC with Leader Dots (Copy-Paste Ready)
    82→  1082→

Use the auto-generated TOC above (TocDocTemplate + multiBuild) whenever possible. Only use this leader-dots approach if you need very specific visual styling that the auto TOC cannot provide - and even then, prefer the auto approach.

   100→  1100→
   101→  1101→story = []
   102→  1102→

   109→  1109→

   111→  1111→toc_style = ParagraphStyle('TOCEntry', parent=styles['Normal'],
   112→  1112→                          fontName='FreeSerif', fontSize=11, leading=16)
   113→  1113→dots_style = ParagraphStyle('LeaderDots', parent=styles['Normal'],
   114→  1114→                           fontName='FreeSerif', fontSize=7, leading=16)
   115→  1115→
   116→  1116→# Build TOC
   117→  1117→toc_data = [
   118→  1118→    [Paragraph('<b>Table of Contents</b>', styles['Heading1']), '', ''],
   119→  1119→    ['', '', ''],
   120→  1120→]
   121→  1121→
   122→  1122→entries = [('Section 1', '5'), ('Section 2', '10')]
   123→  1123→for title, page in entries:
   124→  1124→    toc_data.append([
   125→  1125→        Paragraph(title, toc_style),
   126→  1126→        Paragraph('.' * optimal_dot_count, dots_style),
   127→  1127→        Paragraph(page, toc_style)
   128→  1128→    ])
   129→  1129→
   130→  1130→toc_table = Table(toc_data, colWidths=[None, dots_column_width, page_num_width])
   131→  1131→toc_table.setStyle(TableStyle([
   132→  1132→    ('GRID', (0, 0), (-1, -1), 0, colors.white),
   133→  1133→    ('LINEBELOW', (0, 0), (0, 0), 1.5, colors.black),
   134→  1134→    ('ALIGN', (0, 0), (0, -1), 'LEFT'),
   135→  1135→    ('ALIGN', (1, 0), (1, -1), 'LEFT'),
   136→  1136→    ('ALIGN', (2, 0), (2, -1), 'RIGHT'),
   137→  1137→    ('VALIGN', (0, 0), (-1, -1), 'TOP'),
   138→  1138→    ('LEFTPADDING', (0, 0), (-1, -1), 0),
   139→  1139→    ('RIGHTPADDING', (0, 0), (-1, -1), 0),
   140→  1140→    ('TOPPADDING', (0, 2), (-1, -1), 3),
   141→  1141→    ('BOTTOMPADDING', (0, 2), (-1, -1), 3),
   142→  1142→    ('TEXTCOLOR', (1, 2), (1, -1), TEXT_MUTED),  # From palette --c-muted
   143→  1143→]))
   144→  1144→
   145→  1145→story.append(toc_table)
   146→  1146→story.append(PageBreak())
   147→  1147→doc.build(story)

   215→  1215→### Diagram Embedding Rules (MANDATORY)
   216→  1216→
   217→  1217→**Figures are block-level Flowables.** Every image/diagram in ReportLab MUST be appended to `story` as a standalone `Image()` or wrapped in `KeepTogether([image, caption])`. See SKILL.md § "Diagram Generation Strategy" for the full pipeline.
   224→  1224→
   225→  1225→**🚫 FORBIDDEN: TikZ standalone → PNG pipeline in Report brief.** Report uses ReportLab, not LaTeX. Going through TikZ requires a LaTeX compiler, adds compilation steps, and models frequently produce broken TikZ code. Use Playwright+CSS instead - it's native to the existing cover rendering engine.
   226→  1226→

   234→  1234→story.append(img)                       # block-level Flowable
   235→  1235→```
   236→  1236→
   237→  1237→**⚠️ CRITICAL: Preserve aspect ratio - NEVER hardcode both width and height without reading actual image dimensions.**
   238→  1238→
   239→  1239→**⚠️ CRITICAL: Always constrain to available space - NEVER insert at original size if it exceeds container width/height.**
   240→  1240→
   241→  1241→Pie charts become ellipses, radar charts become diamonds, photos get stretched if you set arbitrary width/height.
   242→  1242→
   243→  1243→**→ MUST READ: `typesetting/overflow.md`** — read the complete bounding box system before writing layout code.
   244→  1244→
   245→  1245→```python
   246→  1246→from PIL import Image as PILImage
   247→  1247→from reportlab.platypus import Image
   248→  1248→from reportlab.lib.pagesizes import A4
   249→  1249→from reportlab.lib.units import inch
   250→  1250→
   251→  1251→def embed_image(path: str, max_width: float = None, max_height: float = None) -> Image:
   252→  1252→    """Embed image with preserved aspect ratio, constrained to container.
   253→  1253→
   254→  1254→    ALWAYS use this pattern. Never hardcode both width and height.
   255→  1255→    If max_width is None, defaults to available_width (page - margins).
   256→  1256→    """
   257→  1257→    if max_width is None:
   258→  1258→        max_width = A4[0] - 2.0 * inch  # Default: A4 width minus 1" margins each side
   259→  1259→    if max_height is None:
   260→  1260→        max_height = A4[1] * 0.35  # ~294pt ≈ 10cm — leaves room for caption + surrounding text on same page
   261→  1261→
   262→  1262→    pil_img = PILImage.open(path)
   263→  1263→    orig_w, orig_h = pil_img.size
   264→  1264→
   265→  1265→    # Scale to fit within BOTH max_width and max_height
   266→  1266→    ratio_w = max_width / orig_w if orig_w > max_width else 1.0
   267→  1267→    ratio_h = max_height / orig_h if orig_h > max_height else 1.0
   268→  1268→    ratio = min(ratio_w, ratio_h)
   269→  1269→
   270→  1270→    return Image(path, width=orig_w * ratio, height=orig_h * ratio)
   271→  1271→
   272→  1272→# Usage:
   273→  1273→available_width = A4[0] - left_margin - right_margin
   274→  1274→img = embed_image('chart.png', max_width=available_width, max_height=300)
   275→  1275→story.append(img)
   276→  1276→```
   277→  1277→
   278→  1278→```python
   279→  1279→# ❌ NEVER do this - distorts the image:
   280→  1280→img = Image('chart.png', width=400, height=250)  # arbitrary height breaks aspect ratio
   281→  1281→```

   500→  1500→#### Option Indentation (MANDATORY)
   501→  1501→```python
   502→  1502→# ReportLab styles for exam papers
   503→  1503→question_style = ParagraphStyle(
   504→  1504→    'Question', fontSize=12, leading=16,
   505→  1505→    leftIndent=0, firstLineIndent=0,
   506→  1506→    spaceBefore=12, spaceAfter=4,
   507→  1507→)
   508→  1508→option_style = ParagraphStyle(
   509→  1509→    'Option', fontSize=12, leading=16,
   510→  1510→    leftIndent=24,   # ← MANDATORY: 24pt indent from question stem
   511→  1511→    firstLineIndent=0,
   512→  1512→    spaceBefore=2, spaceAfter=2,
   513→  1513→)
   514→  1514→```
   515→  1515→
   516→  1516→#### Option Layout Decision
   517→  1517→```python
   518→  1518→def format_options(options):
   519→  1519→    """
   520→  1520→    Decide option layout based on content length.
   521→  1521→    Short options (≤4 chars each, ≤4 options) → 2×2 grid table
   522→  1522→    Long options or >4 options → vertical list, one per line
   523→  1523→    """
   524→  1524→    max_len = max(len(opt) for opt in options)
   525→  1525→    if len(options) <= 4 and max_len <= 6:  # CJK: 4 chars; Latin: 6 chars
   526→  1526→        # 2×2 grid using Table
   527→  1527→        grid = Table(
   528→  1528→            [[options[0], options[1]], [options[2], options[3]]],
   529→  1529→            colWidths=[200, 200], hAlign='LEFT'
   530→  1530→        )
   531→  1531→        grid.setStyle(TableStyle([
   532→  1532→            ('LEFTPADDING', (0,0), (-1,-1), 24),  # Match option indent
   533→  1533→            ('VALIGN', (0,0), (-1,-1), 'TOP'),
   534→  1534→        ]))
   535→  1535→        return grid
   536→  1536→    else:
   537→  1537→        # Vertical list
   538→  1538→        return [Paragraph(f'{opt}', option_style) for opt in options]
   539→  1539→```

   541→  1541→#### Answer Space Reservation (MANDATORY)
   542→  1542→
   543→  1543→**Every question MUST have adequate answer space. No exceptions.**
   544→  1544→
   545→  1545→| Question Type | Minimum Space | Implementation |

   555→  1555→# Answer line helper — light dashed lines for handwriting

   577→  1577→## Data-to-Ink Ratio Rules (MANDATORY for Reports)
   578→  1578→
   579→  1579→**CRITICAL: Do NOT write long paragraphs to describe data trends.** You MUST extract metrics and trends into structured visual elements.
   580→  1580→
   581→  1581→### Pattern Detection Table
   582→  1582→
   583→  1583→Before writing ANY body paragraph, scan the text. If you find any of these patterns, extract them:
   584→  1584→
   585→  1585→| Raw text pattern | ❌ FORBIDDEN | ✅ REQUIRED visual form |
   586→  1586→|-----------------|-------------|----------------------|
   587→  1587→| "revenue grew 12% to $4.2M" | Bury in paragraph prose | CalloutBox with bold `+12%` + `$4.2M` |
   588→  1588→| "latency dropped from 120ms to 75ms" | Long explanatory sentence | CalloutBox or metrics table row |
   589→  1589→| "Q1→Q2→Q3: 10%→25%→40%" | Inline numbers in text | Chart (matplotlib PNG → `Image()`) |
   590→  1590→| "first...second...third..." steps | Paragraph with ordinal words | Numbered Table or process list |
   591→  1591→| "compared to last year / vs Q2" | Nested comparisons in prose | Side-by-side comparison table |
   592→  1592→| "accounted for 60% of total" | Percentage in paragraph | Pie chart or stacked bar chart |
   593→  1593→
   594→  1594→### ReportLab CalloutBox Template
   595→  1595→

   597→  1597→
